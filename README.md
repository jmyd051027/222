소라2,소라2프로,베오3.1,베오3.1 패스트 모두 사용해본 결과 소라2,베오3.1이 크레딧 소모가 적고 처리속도는 빠르지만 결과물이 지시사항을 발 반영하지 못햐 품잘아 떨어졌다.
소라2프로,베오3.1패스트는 크레딧 사용이 굉장히 크지고 제작시간이 비교적 길게 사용되지만 지시사항을 결과물에 보다 더 잘 반영하여 결과물의 품일이 뛰어나다.
